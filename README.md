# VoronoiProject
Repósitorio voltado à criação de um algoritmo de busca e escolhas de vértices com pesos em um diagrama de Voronoi de maneira eficiente para a disciplina de *Mátematica Discreta Voltada para Computação* ministrada pelo professor do *Cin (Centro de Informática) - UFPE*, Pedro Machado Manhães de Castro.
